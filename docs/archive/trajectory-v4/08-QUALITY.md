## 1. 可访问性（WCAG 2.2 AA）

### 1.1 已在设计层解决的

| 条款 | 等级 | 处理 |
| :--- | :--- | :--- |
| 1.4.3 对比度（最低） | AA | 全部色彩组合已实测，见 [`01-DESIGN.md`](01-DESIGN.md) §2。正文最低 4.59:1 |
| 1.4.11 非文本对比 | AA | 表单控件边框（暗 3.38 / 亮 3.21）、焦点环（暗 7.15 / 亮 4.77） |
| 2.2.2 暂停/停止/隐藏 | A | 全站唯一的循环动画 5 秒后自动停止 |
| 2.3.1 闪光阈值 | A | 无任何闪烁类动效 |
| 2.3.3 交互中的动画 | **AAA** | `prefers-reduced-motion` 完整支持 —— 主动的工艺承诺，超出法定底线 |
| 2.5.5 目标尺寸 | AAA | 所有触控目标 ≥44×44px |
| 1.4.12 文本间距 | AA | 中文行高 ≥1.75（正文），用户覆盖样式不会导致内容截断 |

### 1.2 实现时必须做到的

- **跳转链接**：第一个 Tab 目标是「跳到主内容」（`.skip-link` 已在 tokens 中定义）
- **语义标签**：`<header>` `<nav>` `<main>` `<footer>` `<section aria-labelledby>`，不用 `<div>` 堆结构
- **标题层级**：每页有且仅有一个 `<h1>`，层级不跳级
- **焦点可见**：`:focus-visible` 焦点环全站可见，且**不做动画**
- **焦点管理**：模态框打开时焦点进入、关闭时归还触发元素（Radix 提供）
- **图片替代文本**：证书图的 `alt` 描述奖项内容，不是"证书图片"；纯装饰图 `alt=""`
- **表单**：`<label for>` 显式关联、`aria-invalid`、`aria-describedby`、错误可被屏幕阅读器读到
- **状态消息**：提交结果用 `role="status"` + `aria-live="polite"`（4.1.3）
- **键盘**：所有交互（含证书查看、方向切换、主题切换、移动端菜单）纯键盘可完成
- **动效不是唯一信号**：每个用动效表达的状态变化，必须有静态伴随信号

## 2. 性能

### 2.1 预算

| 指标 | 目标 | 上限 |
| :--- | :--- | :--- |
| LCP（移动端 4G） | < 2.0s | 2.5s |
| INP | < 150ms | 200ms |
| CLS | < 0.02 | 0.1 |
| 首屏 JS（`/`，gzip） | < 120KB | 180KB |
| 全站单页 JS（gzip） | < 150KB | 200KB |
| 字体总体积 | < 180KB | 250KB |
| Lighthouse 性能（移动端） | ≥ 92 | 90 |

### 2.2 关键手段

| 手段 | 说明 |
| :--- | :--- |
| RSC 优先 | 内容展示组件零客户端 JS。只有 7 个组件带 `'use client'` |
| 中文正文零字体下载 | 走系统栈 `PingFang SC` / `Microsoft YaHei`，覆盖 >95% 目标用户 |
| 中文标题字体子集化 | 只保留实际用到的约 300 字形，产物 <40KB（完整字体约 9MB） |
| `adjustFontFallback` | 消除字体切换造成的 CLS |
| 字体自托管 | 不依赖 Google Fonts 运行时 CDN（国内校园网不可靠） |
| 图片 AVIF/WebP + `srcset` | 通过 `next/image` |
| CSS 滚动驱动动画 | 主线程无关，天然流畅 |
| 不引入 GSAP / Lenis / Three.js | 见 [`05-ARCHITECTURE.md`](05-ARCHITECTURE.md) §1 |
| 只动可合成属性 | `transform` / `opacity` / `clip-path` / `mask-image` |

在**中端安卓机**（约骁龙 6 系）上实测，不只看 Lighthouse 模拟：

- [ ] 首页从点击到可交互的主观体感

- [ ] `/works` 底片聚光在触屏上的降级路径

## 3. SEO

### 3.1 每页元数据

```ts
// 通过 lib/seo.ts 的工厂函数统一生成
{
  title: '<页面名> · 云飞扬社团',
  description: '<该页专属描述，60–120 字，含真实关键词>',
  alternates: { canonical: '<绝对 URL>' },
  openGraph: { type: 'website', locale: 'zh_CN', images: ['<该页 OG 图>'] },
  twitter: { card: 'summary_large_image' },
}
```

### 3.2 结构化数据（JSON-LD）

| 位置 | 类型 |
| :--- | :--- |
| 根布局 | `Organization`（名称、成立年份、隶属、Logo、口号、`sameAs`） |
| 每个非首页 | `BreadcrumbList` |
| `/tracks/[slug]` | `Course` 或 `EducationalOccupationalProgram` |
| `/join` | `Event`（招新期，如有明确时间） |
| `/awards` | 每条奖项的 `Award`（作为 `Organization` 的 `award` 字段） |

### 3.3 落地页策略

多页拆分的一个直接收益是长尾搜索的落地精度：

| 搜索词 | 应落到 |
| :--- | :--- |
| 南阳理工 云飞扬 社团 | `/` |
| 南阳理工 人工智能 社团 / 学生组织 | `/tracks/ai` |
| 云飞扬 招新 / 怎么加入 | `/join` |
| 南阳理工 计算机 竞赛 获奖 | `/awards` |

每个方向详情页应有独立的 `title` / `description` / `h1`，而不是首页的锚点。

### 3.4 其他

- `sitemap.xml` 由 `app/sitemap.ts` 生成，含全部路由（当前 13 个 URL，随作品详情页数量增减）
- `robots.txt` 允许全部抓取
- `<html lang="zh-CN">`
- 语义化 URL：`/tracks/ai` 而非 `/tracks/1`
- 内链：每个方向详情页互相链接（前后导航）、每页至少一条通往 `/join`

## 4. 内容真实性红线

**这是本项目最重要的一条质量规则。**

### 禁止

- ❌ 编造数据："效率提升 10 倍""99.9% 可用性""3 倍学习效率"
- ❌ 编造奖项、成员数量、项目状态
- ❌ 占位文案：`lorem ipsum`、"特性一/二/三"、"敬请期待"、"示例内容"
- ❌ 外部占位图 CDN：`unsplash.com` / `placehold.co` / `picsum.photos` / `placekitten.com`
- ❌ 图库通用配图充当项目截图或实验室实拍

### 规则

> **拿不到真实内容的模块，整块不上线。**

区块组件在数据缺失时返回 `null`，不渲染骨架、不渲染"敬请期待"。少一个模块不丢人，上一个假模块才丢人。

**用 schema 强制执行**：`workSchema.detail.limits` 是必填的（`.min(2)`）。一个只写优点、不写边界的项目详情页在构建时就会失败，不需要靠人工审查记得这条。

### 两条必须写在页面上的限定

| 项目 | 必须如实说明 |
| :--- | :--- |
| 智光耀城智慧路灯平台 | **当前所有设备、遥测、控制结果和告警均为模拟数据，不连接真实灯杆**。这不是缺点，是项目自己 README 里就写明的定位；官网如果把它说成真实物联网平台，就是造假 |
| 智光耀城的测试数字 | 195 / 425 / 9 是 **2026-07-21 的归档验收基线**，不是"持续通过"。照抄数字，保留限定 |

### 一条安全红线

源码仓库 `G:\Code\IDEA\zgyc` 的 `信息.md` 含服务器 IP 与 SSH 私钥路径，`.env` 含数据库凭据。**这些内容不得以任何形式出现在官网、项目截图或演示材料里。** 截图前先确认：无真实主机名、无账号、无 token、无内网地址。

### 措辞

奖项与成果用**事实陈述**，不用形容词堆砌。

| ✅ | ❌ |
| :--- | :--- |
| 国家级二等奖 | 在激烈竞争中脱颖而出，彰显了团队卓越的工程技术水平 |
| 已部署投入日常教学 | 打造了行业领先的智慧教育解决方案 |
| C 语言集训 25 人次 · 45 学时 | 开展了丰富多彩的技术培训活动 |

## 5. 浏览器支持

| 浏览器 | 版本 | 支持级别 |
| :--- | :--- | :--- |
| Chrome / Edge | 最近 2 个版本 | 完整（含 CSS 滚动驱动动画 + View Transitions） |
| Safari | 17+ | 完整（Safari 18+ 支持滚动驱动动画） |
| Firefox | 最近 2 个版本 | 功能完整；滚动驱动动画呈现静态终态 |
| 微信内置浏览器 | 当前版本 | 功能完整；部分动效降级。**必测** |
| QQ 内置浏览器 | 当前版本 | 功能完整；部分动效降级。**必测** |
| 移动 Safari / Chrome | iOS 16+ / Android 10+ | 完整 |

**渐进增强策略**：所有高级特性（CSS 滚动时间线、View Transitions、`mask-image`）在不支持时呈现**有意义的静态终态**，而不是坏掉或空白。功能可用性不依赖任何一个高级特性。

**微信 / QQ 内置浏览器**是国内校园场景的主入口（招新二维码与海报扫码），不是"顺便看看"的边缘环境。其内核版本滞后、外链有警告条、微信内禁止唤起 QQ 深链等约束，详见 [`09-MOBILE.md`](09-MOBILE.md) §9。

## 6. 代码质量门禁

CI 中任何一项失败即阻止合并：

```
1. tsc --noEmit                    类型检查（strict）
2. eslint                          含 eslint-plugin-jsx-a11y
3. vitest run                      content schema 校验
4. next build                      构建
5. playwright test                 关键路径 e2e
6. axe 扫描（在 playwright 内）      零 serious / critical
7. lhci autorun                    性能 ≥90、可访问性 =100
```

### 建议的自定义 lint 规则

| 规则 | 检查 |
| :--- | :--- |
| `no-raw-hex` | 组件文件中的裸十六进制色值（`:root` 除外） |
| `no-emoji-icon` | `<h*>` / `<button>` / `class*="icon"` 中的 emoji |
| `no-placeholder-cdn` | `unsplash` / `placehold` / `picsum` 域名 |
| `no-filler-copy` | `lorem ipsum` / `敬请期待` / `示例` |
| `accent-budget` | 单个页面文件中 `accent` 相关类名出现次数 >2 时告警 |

前四条可以用简单的 grep 脚本实现，成本很低但拦得住最容易犯的错。
