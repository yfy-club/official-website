- 桌面方向区最大宽度扩展至 1600px，五张卡片保持等宽，并由真实 DOM 锚点生成平滑曲线，消除固定 SVG 坐标造成的悬空和错位。
- 移动端改为灰色主干、短分支和独立内容卡片，连接线与内容层级分离；320px 下五张卡片均保持在视口内。

- 鼠标悬停和键盘聚焦会同步强调对应桌面路线，触屏布局保持完整静态反馈。
