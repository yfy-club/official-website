## 3. 运转机制（`/about` ⑤ ⑥）

**规章与管理**
- 清晰的技术路线与阶段考核任务（C 语言期中考、C++ 课设验收、Linux 综合实操考、MySQL 控制台实训）
- **工位打卡机制**：常规周固定打卡 **16~22 小时**，期末复习周最长可达 **30 小时**（考勤机考勤，严禁盗刷时长与违规打卡）
- 打卡签到 · 任务跟踪 · 阶段考核退出机制

**学习体系**
- 分阶段、成体系的技术路线学习规划（大一 6 阶段由浅入深）
- 强调代码自学、发现问题与自主解决问题的能力；善用官方文档、报错日志与 AI 提效
- 每周例会交流与项目进度同步

**环境维护**
- 严格执行《云飞扬值日带班表》，每日轮值大扫除、周六深度维护
- 离室推齐座椅、关闭灯光电扇电脑电源、双重锁门，保障实验室日常软硬件与安全

**新生培育与师徒制**
- 严谨选拔：招新面试 + 编程基础多轮考核
- **一对一师徒制**：每位新成员配备一名高年级技术骨干定向辅导；阶段课设与大作业**必须由师傅一对一逐行审阅代码、纠正规范、查验创新点**后方可通过

**阶段验收与工程标准**
- **JavaSE 综合大作业**：要求满足三层分层设计（Entity / Service / Controller）、面向接口编程、集合嵌套结构、基于 Comparator 的多维排序、结构化文件数据持久化与容错解析、追加式操作日志、自定义业务异常与输入合法性校验。
- **Web 前端大作业**：掌握 HTML5 / CSS Flex 布局与 JavaScript DOM 操作，实现平滑过渡轮播组件与多场景页面（官网展示/电商/后台/专题页），完成桌面与移动端响应式适配。
- **Git 版本控制**：以 GitHub 真实提交记录作为评价依据，要求体现分阶段提交过程、包含分支（如 `dev`）开发与合并、规范编写 Markdown README，禁止一次性提交全部代码。
- **MySQL 数据库实训**：涵盖 DDL 表结构定义、DML 数据维护、DQL 复杂多表联合查询与 DCL 权限配置，要求在查询控制台执行并保留完整解题记录。

**培训成果（真实数据，直接可用）**
- C 语言系统集训：25 人次 · 45 学时
- C++ 面向对象进阶：14 人次 · 8 学时
- Linux 系统与常用指令综合考查
- MySQL 数据库设计与控制台综合实操通关

**激励与淘汰**
- 竞赛获奖、项目贡献突出者给予表彰，优先推荐高阶竞赛、教师科研课题与企业实习
- 长期未达阶段考核、出勤严重不达标者执行退出机制

## 8. 招新内容（`content/faq.ts` + `/join`）

### ② 我们在找什么（正反筛选清单）

**我们在找谁（适合加入）**：
1. **对代码与技术有纯粹的好奇心与自驱力** —— 想弄清楚一行代码如何变成真实运转的系统，渴望动手写出自己的作品。
2. **能保证每周固定的工位专注学习时间** —— 能保证每周投入 16~22 小时在实验室工位深耕，持之以恒。
3. **愿意理解底层原理，想驾驭 AI 而非成为调包侠** —— 愿意认真面对代码报错、接受师傅的逐行审码与阶段实操考核。

**不适合谁（反面清单）**：
1. **只想混社团履历、挂名水学分或期末突击者** —— 社团没有划水空间，长期无产出将被严格执行退出机制。
2. **无法保证工位自习时间、抗拒代码考核者** —— 技术靠时间与代码量堆出来的，无法投入时间者请勿报名。
3. **只依赖 AI 盲目生成代码而不求甚解者** —— 我们培养的是能驾驭前沿工具的未来工程师，而非被黑盒代码裹挟的初学者。

### ⑤ 常见问题 FAQ 官方解答
1. **零基础可以报名吗？**
   - **答**：可以。社团提供配套的任务需求文档与渐进式学习路线（涵盖 Git 协作、Web 响应式页面、JavaSE 分层设计与 Python 数据处理），并为每位新成员配备高年级骨干一对一指导，按部就班即可完成过渡。我们要的不是已经精通的人，而是想学会并愿意投入时间的人。
2. **每周需要投入多少时间？**
   - **答**：常规教学周要求每周在实验室工位打卡 16~22 小时，期末复习与冲刺周最长可达 30 小时。编程是一门实践性学科，足够的代码量和专注度是快速成长的唯一保障。
3. **和其他社团/工作室有什么不同？**
   - **答**：云飞扬坚持“真工程、真考核、真传承”。从大一的代码三层分层设计、面向接口多态、文件持久化容错、Git 分支协作与 MySQL 控制台实训，到大二的云服务器公网部署、微服务与 Agent 编程工具协同，再到大三的考研 408 与就业实习双通道分流，全程依托真实项目与高规格竞赛牵引。
4. **考核不通过会怎样？退出机制具体怎么执行？**
   - **答**：每次阶段任务有明确验收节点与讲评复盘；对于长期未达阶段考核、严重违纪或出勤长期不达标者，将严格执行退出机制。
5. **五个技术方向什么时候定？可以更换吗？**
   - **答**：大一上学期统一打牢 C/C++ 与编程基础，寒假及大一下学期根据个人兴趣与能力进行 Java/Python 方向分流。方向选择以兴趣与长远规划为主，经导师评估后可适度调整。
6. **加入后能参加哪些竞赛？**
   - **答**：社团重点组织参与蓝桥杯、中国软件杯、中国国际大学生创新大赛（互联网+）、iCAN 国际创新创业大赛、ACM/天梯赛、数学建模以及智能汽车/机器人等教育部认可的 A 类赛事。
7. **需要自带电脑吗？实验室提供什么？**
   - **答**：建议自带笔记本电脑用于日常编码与调试。社团依托大学生科技园提供专属工位、实验室环境、团队打印机、共享服务器算力及考研资料库。
8. **大二、大三还能加入吗？**
   - **答**：社团主要在每年秋季面向大一新生进行成体系招新；对于有扎实技术基础、项目经验或竞赛获奖的高年级同学，可经技术考核破格特招。
